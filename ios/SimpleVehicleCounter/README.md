# 簡易車両カウンター

iPhoneを固定して道路を映し、車両がカウントラインを越えた回数を簡易的に数えるiOSアプリです。

## 機能

- カメラ映像の動体検出と車両らしさフィルターによる車両候補の検出
- カウントライン通過で車両台数を自動加算
- 手動の+1 / -1補正
- 認識距離バーによる検出感度の調整
- 端末内処理

## 注意

このアプリは簡易調査向けです。人や小さい二輪を拾いにくいよう、検出した動体の幅・高さ・形・位置で絞ります。夜間、雨、逆光、手持ち撮影、車両の重なりがある環境では数え漏れや重複が起きます。三脚などで端末を固定し、車両がラインを横切る構図で使うと安定します。
