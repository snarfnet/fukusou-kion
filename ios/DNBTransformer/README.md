# CHOP//170

音声ファイルを読み込み、指定BPMのドラムンベースへ自動変換するiOSプロトタイプです。

## 現在の機能

- iPhoneの「ファイル」から音声を読み込み
- 140〜190 BPMを指定
- Liquid / Jungle / Darkの3スタイル
- 素材の自動スライス
- キック、スネア、ハイハット、サブベースの自動生成
- 16小節のWAVを生成
- アプリ内再生と共有

## 起動

1. MacにXcodeGenをインストールします。
2. このフォルダで `xcodegen generate` を実行します。
3. `DNBTransformer.xcodeproj` をXcodeで開き、署名チームを選んで実機またはシミュレータで起動します。

音声処理は端末内で完結します。読み込んだ音を外部サーバーへ送りません。
