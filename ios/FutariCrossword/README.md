# ふたりでクロスワード

喫茶店で彼女と一緒に解いている雰囲気の、SwiftUI製クロスワードアプリです。

## 開き方

1. macOSでXcodeGenをインストールします。
2. このフォルダで `xcodegen generate` を実行します。
3. `FutariCrossword.xcodeproj` をXcodeで開きます。
4. iOS 17以降のシミュレータまたは実機で実行します。

## 現在の機能

- 1×1〜20×20の盤面生成
- 盤面のピンチ拡大とスクロール
- ひらがな入力、1文字ヒント、答え合わせ
- 8種類の表情、まばたき、状況別の一方的な会話
- 単語辞書と会話バンクをコードから追加可能
- 生成器の1〜20サイズ境界テスト

`WordBank.swift` は初期データです。本番公開前に校正済み辞書をJSONまたはSQLiteへ移し、数千語へ増やす想定です。
