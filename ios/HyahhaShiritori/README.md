# ヒャッハーしりとり

世紀末しりとりカードバトルゲームのiOS版です。

## 作ったもの

- SwiftUIアプリ本体
- しりとり判定
- 6枚カード選択
- 「ん」罠カード
- ミス3回敗北
- 初級・中級・上級
- 10人の敵キャラクター
- 進行状況の保存
- 手描き風のアプリアイコン

## 画像について

この作業フォルダ、Downloads、Pictures、Desktop、StabilityMatrixの出力先を探しましたが、ヒャッハーしりとり用だと分かる画像は見つかりませんでした。

あとで画像が見つかったら、`HyahhaShiritori/Assets.xcassets` に imageset を追加すれば差し替えできます。
