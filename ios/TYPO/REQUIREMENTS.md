# TYPO 仕様と確認結果

対象は「TYPO — 文字の建築家.txt」です。追加課金・ストア・購入復元・有料制限はユーザーの指示で削除し、全機能を追加購入なしで使える構成にしました。

## 実装

| 仕様 | 対応 |
|---|---|
| ホーム・入力・スタジオ・保存・ギャラリー・共有 | ネイティブSwiftUIで実装。作成から再起動・共有までUIテスト成功 |
| コレクション・展示・設定 | 8プリセット、スロー回転、照明変化、自動で隠れる操作ボタン、設定画面 |
| 文字造形 | 最大12文字・3行。Noto Serif CJK JP同梱。Core Textの輪郭をSceneKitで押し出し |
| 穴と曲線 | 永の描画画像を確認。A・8・Oは生成画像内の穴を自動検証 |
| 形状 | 厚さ0–100、ベベル0–30（厚さの半分まで）、字間、行間、アーチ、滑らかさ、回転XYZ、拡大・位置 |
| 文字ごとの編集 | 複数選択、グループ、整列、移動・回転・拡大、レイヤー、個別素材。選択表示の回帰テストも成功 |
| 操作 | 1本指回転、2本指移動、ピンチ、長押し選択、ダブルタップ。展示中のダブルタップは編集へ戻る |
| Undo / Redo | 60操作まで保持。作品ごとに履歴も保存 |
| 素材・光 | 6素材、粗さ・金属度・傷・クリアコート、3灯、反射環境、床の影、5背景、構図プリセット |
| 保存 | 端末内JSON、schemaVersion、atomic更新、破損ファイル分離、自動保存、複製、削除確認 |
| 画像 | PNG、透明PNG、JPEG、HEIC対応判定。1080/2160正方形、ストーリー、A4比率、4K |
| 動画 | 30fps MP4、5/10/15秒。進捗・中止・背景移行・メモリ警告を処理 |
| 画面幅 | 狭い画面は上下、広い画面は左右。パネルの左右交換。未確認の開閉角度APIに依存しない |
| 日英・アクセシビリティ | 日英リソース、Dynamic Type、VoiceOverラベル、Reduce Motion。VoiceOver時は展示の終了ボタンを保持 |
| 省電力・発熱 | 60/30fps設定、影とアンチエイリアスの品質調整 |
| 法務・プライバシー | OFL全文、アセット台帳、作品利用説明、PrivacyInfo.xcprivacy。広告・分析・購入SDKなし |

## 確認できたこと

GitHub Actionsの最終検証は **39429569584**。iPhone 17 ProとiPad Pro 13-inch (M5)の両方で、機能テスト15件・UIテスト2件が成功しました。

- 字形、複数行、グループ、個別素材、履歴、JSON復元、破損データの分離
- 透明PNG、画像エンコーダー、全5解像度の実出力
- MP4の5/10/15秒・30fpsでの出力と時間、中止処理（時間テストは128×128）
- 初回保存60秒以内、縦横回転、保存、再編集、再起動、履歴保持
- 共有シートの表示と終了、展示からダブルタップで戻る操作
- 日本語と英語のホーム表示
- Windows上のモデル実行テスト37項目

## 実機での確認が必要なこと

シミュレータの成功は実機の性能保証ではありません。60/30fps、発熱、連続4K動画出力、VoiceOverの読み上げ、低メモリ・空き容量不足時の実機動作は未測定です。ピンチ・2本指移動・長押しの実機での操作感も確認対象です。

Glassは透明材質による屈折風の表現です。Metal独自の屈折シェーダではありません。透過動画は、元の仕様で対応可否検証後とされているため提供していません。特定の折りたたみ機種の実機確認や、App Store正式審査への提出は今回の範囲に含めていません。
