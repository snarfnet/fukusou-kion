# 民族衣装カメラ

全身写真を撮影または写真ライブラリから読み込み、100種類の民族衣装を重ねて保存するiPhoneアプリです。

## 収録内容

- 女性用50種類、男性用50種類
- 撮影中の頭頂・肩・腰・膝・足元ガイド
- 写真ライブラリからの読み込み
- 衣装の移動、拡大縮小、回転
- 3:4比率での合成写真保存
- 性別切り替え、衣装検索
- 地域、衣装概要、歴史、着用場面、素材、参考資料

衣装画像はImageGenで作成し、緑のクロマキー背景を除去した1024×1536の透過PNGへ統一しています。画像は人物へ厳密に着せ替える方式ではなく、写真の上へ衣装を重ねる方式です。

## 開発環境

- iOS 17以降
- Xcode 16以降
- SwiftUI
- XcodeGen（`project.yml`から再生成する場合のみ）

## プロジェクト生成

macOSで同梱のプロジェクトを開きます。

```sh
open WorldDressCamera.xcodeproj
```

構成を変更してプロジェクトを再生成する場合は、`xcodegen generate`を実行します。

実機でカメラを確認する場合は、署名チームとBundle Identifierを開発環境に合わせてください。

## 検査

画像とカタログの対応、男女件数、PNGサイズ、アルファチャンネル、透明な四隅を検査します。

```sh
node scripts/verify_assets.mjs
node scripts/verify_project.mjs
```

画像の再生成時は、ImageGen出力を次のスクリプトで透過・正規化・登録できます。

```sh
node scripts/install_generated_asset.mjs /path/to/generated.png women_japan_furisode
```

## 文化情報について

「伝統衣装」は時代、地域、共同体、家族、宗教、用途によって異なります。アプリでは各項目を一例として示し、単一の固定的な民族像として扱わない注記を表示します。公開前に、必要に応じて当該文化の専門家やコミュニティによる確認を行ってください。
