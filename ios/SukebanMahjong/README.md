# 雀華番長 — 全国制覇編

昭和末期の日本を舞台に、全国のスケバンと二人麻雀で戦うiOS向けストーリーゲームです。

- 一気通貫、三色同順、三色同刻、一盃口、二盃口

- 七対子25符、面子・雀頭・待ち形の符計算
- 符と翻による通常点、満貫、跳満、倍満、三倍満、役満
- 国士無双、大三元、四暗刻、字一色、清老頭、大四喜、小四喜、四槓子

## ビルド

XcodeGenを導入したMacで実行します。

```sh
cd ios/SukebanMahjong
xcodegen generate
open SukebanMahjong.xcodeproj
```

ビルド、XCTest、署名なしArchiveをまとめて検証する場合は、次を実行します。

```sh
bash Tools/VerifyOnMac.sh
```

## ルールについて

物語を短時間で進められるよう、対局は二人用のアレンジルールです。符と翻から点数を計算し、東四局終了時の点差で学校を制覇します。親は和了または流局テンパイで連荘し、同点は防衛校の勝ちです。鳴きはチー、ポン、大明カン、暗カン、加カンに対応しています。

## テスト

Xcodeで `SukebanMahjongTests` を実行します。通常形、七対子、不成立形、役と点数、牌山136枚、ドラ巡回、フリテン、役なしロン禁止、親点、本場、連荘、供託棒、対局保存を検査します。

GitHub Actionsの `Sukeban Mahjong iOS` はmacOS上でXcodeGenを実行し、利用可能なiPhoneシミュレータを選んでビルドとXCTest、署名なしArchiveを行います。結果の `.xcresult` と `.xcarchive` は7日間保存します。

麻雀エンジンと保存層はSwift Packageとしても分離しています。WindowsではSwift ToolchainとVisual Studio Build Tools 2022を導入後、次を実行します。

```powershell
.\Tools\TestCoreOnWindows.ps1
```

Swift 6.3.3のWindows環境で、麻雀ロジック・保存・物語データを含む全75件のXCTestが成功しています。
