# 簡易自転車カウンター

iPhoneを固定して道路を映し、自転車がカウントラインを越えた回数を簡易的に数えるiOSアプリです。

## 機能

- Core ML / Visionによる自転車候補の検出
- カウントライン通過で自転車台数を自動加算
- 手動の+1 / -1補正
- 認識距離バーによる検出感度の調整
- 端末内処理

## 注意

このアプリは簡易調査向けです。YOLOのbicycle検出を使い、車や歩行者を拾いにくくします。夜間、雨、逆光、手持ち撮影、自転車の重なりがある環境では数え漏れや重複が起きます。三脚などで端末を固定し、自転車がラインを横切る構図で使うと安定します。
