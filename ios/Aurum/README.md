# Aurum — 古の錬金帖

古典的な錬金術・ヘルメス思想・象徴論を、日々の自己省察へ翻訳した SwiftUI アプリです。占いや吉凶判定はありません。

## 生成

```sh
xcodegen generate
open Aurum.xcodeproj
```

必要環境: Xcode 16、iOS 17 以降。データは端末内の UserDefaults に保存します。ネットワーク通信、広告、課金、アカウント登録はありません。

## 対応言語

- 日本語
- English
- Español
- 简体中文
- 한국어

表示はiPhoneの優先言語に自動で切り替わります。英語を基準言語にしているため、追加言語で未翻訳の知恵本文がある場合は英語を表示します。アプリ名も言語ごとにローカライズしています。

## 追加した継続機能

- 知恵の全文検索とお気に入り絞り込み
- 書庫の知恵から直接実践を開始
- 記録の削除と実践日数の表示
- 錬金帖をテキストとして共有・書き出し

## 書籍の扱い

着想元はユーザー提供の書籍フォルダです。PDF本文や図版は同梱せず、歴史的概念を独自の短文と安全な実践へ再構成しています。公開前に各資料の権利状態を確認してください。

## ビジュアル

アプリアイコン兼メインアートは imagegen スキルの組み込み画像生成で制作しました。最終プロンプトは `IMAGEGEN_PROMPTS.md` に保存しています。
