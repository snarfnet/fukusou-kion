# 卒アル右上メーカー

集合写真に参加できなかった人を、昔の卒業アルバムにある右上の丸い欠席者枠として追加するSwiftUIアプリです。

## MVP

- 無料テンプレート3種類
- 有料テンプレート5種類
- PhotosUIで顔写真を選択
- 丸窓の位置、サイズ、写真の拡大縮小、回転を調整
- 年度、タイトル、学校名、学年、組、欠席者名、コメントを入力
- CoreGraphicsで端末内書き出し
- 写真アプリ保存と共有
- StoreKit 2で「思い出行事パック」を解放
