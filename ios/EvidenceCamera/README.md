# 証拠カメラ

写真に信頼性を付けるiOSカメラアプリです。

## 主な機能

- カメラ撮影
- 撮影日時の保存
- GPS位置情報と住所の保存
- 方角の保存
- 端末の傾きの保存
- 写真データとメタ情報から作るSHA-256ハッシュ
- 連続撮影ログ
- 写真詳細画面での位置、方角、傾き、ハッシュ確認
- 写真または記録情報の変更検出
- 写真ライブラリから読み込んだ証拠写真のデータ確認

## 開き方

macOSで次を実行します。

```sh
cd ios/EvidenceCamera
xcodegen generate
open EvidenceCamera.xcodeproj
```

実機でカメラ、位置情報、方角、モーション情報を確認してください。
