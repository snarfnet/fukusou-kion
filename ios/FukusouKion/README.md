# 服装気温

天気、気温、降水確率から今日の服装を提案するSwiftUIアプリです。

## 入っている機能

- Core Locationで現在地を取得
- WeatherKitで現在天気と7日予報を取得
- 最高気温、最低気温、降水確率、風速、UV指数を表示
- 気温別の服装提案
- 降水確率40%以上で折りたたみ傘、70%以上で普通の傘を提案
- 朝7時、8時、9時のローカル通知
- ホーム下部の広告枠
- 週間画面前の広告差し込み口
- 暑がり、普通、寒がりの体感設定
- 女性向けを初期設定にした提案切り替え
- 将来の広告なし課金を差し込みやすい広告サービス層

## 実機で使う前の設定

1. Apple DeveloperでApp IDにWeatherKitを有効化します。
2. XcodeでTeamとBundle IDを自分のものに変更します。
3. 広告SDKを入れる場合は、`AdService` を本番IDに差し替えます。
4. `project.yml` からXcodeGenでXcodeプロジェクトを生成します。
