# ごみ日カレンダー

GPSで現在地を取り、逆ジオコーディングで住所に変換するSwiftUIアプリです。

## 現状

- CoreLocationで現在地を取得
- CLGeocoderで住所を表示
- 自治体名と町名をキーに収集ルールを照合
- 直近の収集日を一覧表示

収集曜日は自治体ごとに違います。アプリ内の「仮ルール追加」は動作確認用です。公開前に、各自治体の公式カレンダーから正しいルールへ差し替えてください。

## プロジェクト生成

```bash
cd ios/GomiCalendar
xcodegen generate
```

生成後、`GomiCalendar.xcodeproj` をXcodeで開いて実機確認します。位置情報はシミュレータでもテストできますが、実住所の精度確認は実機が向いています。
