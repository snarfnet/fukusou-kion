## Japanese Description

天使の手紙は、毎日ひとつの短いメッセージを届ける内省アプリです。

天使語風の言葉、日本語、英語を並べて表示します。光、夢、月、沈黙、心などのテーマから、今日の気持ちを整える言葉を読めます。

主な機能:
- 365日分のメッセージ
- 天使語風、日本語、英語の3段表示
- 今日の小さな行動
- 気に入った手紙の保存
- 毎朝のローカル通知

未来を断定する占いではありません。静かに自分を整えるための小さな手紙です。

## English Description

Daily Angel Letter gives you one short reflective message each day.

Each letter appears in an angelic-inspired phrase, Japanese, and English. Read calm words around themes like light, dreams, the moon, silence, and the heart.

Features:
- 365 daily messages
- Angelic-inspired, Japanese, and English text
- One tiny daily action
- Save favorite letters
- Local morning reminders

This app does not predict the future. It is a quiet daily letter for reflection.
