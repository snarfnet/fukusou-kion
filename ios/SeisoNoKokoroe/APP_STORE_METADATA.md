# App Store Metadata

## 日本語

### アプリ名
清掃の心得

### サブタイトル
豆知識とホウキ針タイマー

### 説明
清掃の心得は、掃除を小さく始めるための豆知識アプリです。

キッチン、浴室、トイレ、玄関、窓、床、家電、収納など、暮らしの中でよく使う場所ごとに清掃のヒントを収録。豆知識はタイプライターのように流れ、気になった場所からすぐに掃除を始められます。

ホウキが針になった清掃タイマーも搭載。3分、5分、10分、15分、30分から選んで、短い掃除に集中できます。

主な機能:
- 清掃の豆知識10000件
- 場所別の検索
- タイプライター風の豆知識表示
- 今日の風水掃除アドバイス
- ホウキ針タイマー
- アラーム通知

完璧に掃除しなくても大丈夫です。今日は一か所だけ整える。そんな気持ちで使えるアプリです。

### キーワード
掃除,清掃,片付け,家事,タイマー,風水,豆知識,キッチン,浴室,トイレ

### プロモーションテキスト
豆知識を読んで、ホウキ針タイマーで短く掃除。今日は一か所だけ整えましょう。

## English

### Name
Cleaning Kokoroe

### Subtitle
Tips and broom timer

### Description
Cleaning Kokoroe helps you start cleaning with one small action.

Browse practical cleaning tips for the kitchen, bathroom, entryway, windows, floors, appliances, storage, and more. Tips appear in a typewriter-style flow, with a daily feng shui-inspired cleaning suggestion and a broom-hand timer for short sessions.

Features:
- 10,000 cleaning tips
- Search by place
- Typewriter-style tip display
- Daily lucky cleaning spot
- Broom-hand cleaning timer
- Alarm sound

No need to clean everything at once. Pick one spot, set a timer, and begin.
