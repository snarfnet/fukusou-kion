# 職人スマホDX

「職人スマホ」のデラックス版として作る新規SwiftUIアプリです。
元アプリの核は、デジタル角度計、水平器、単位変換です。DX版では、測定した値を現場で残し、写真やPDFで共有できるようにします。

- 元アプリのApple ID: `6764789904`
- 元アプリのバンドルID: `com.snarfnet.shokuninwatch.ios`
- DX版のApple ID: App Store Connectで新規作成後に設定
- DX版の想定バンドルID: `com.tokyonasu.shokuninsumahodx`

## DX版の主要機能

- 角度計DX
- 2軸水平器
- 尺・寸・坪・畳・inch・feetの単位変換
- 測定メモ保存
- 写真への測定ラベル追加
- ゼロ補正と基準角度プリセット
- 勾配計算
- 材料数量計算
- 現場チェックリスト
- 水平時の音・振動通知
- 測定履歴のPDF出力
- 中心線ガイド
- 現場ごとの測定セット
- よく使う変換のお気に入り
- 測定値のOK / NG自動判定しきい値
- 現場テンプレ（内装・外構・設備）
- 写真の矢印・丸印注釈
- 測定履歴の検索
- PDF共有用QRコード
- よく使う材料単価の登録
- 測定スタンプ帳
- ビフォーアフター比較
- 音声メモ入力
- 電卓付き単位変換
- 許容差プリセット
- よく使う現場セットの複製
- レーザー風オーバーレイ
- 水平OKアニメーション
- 現場レポート表紙自動生成
- 測定ミス防止アラート
- 履歴のタグ管理
- 材料ロス率テンプレ

入力データは端末内のUserDefaultsに保存します。外部APIやトラッキングは使いません。
