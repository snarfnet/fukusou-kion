# 職人スマホSuper DX

現場で測る、残す、説明するための SwiftUI アプリです。

- 想定バンドルID: `com.tokyonasu.shokuninsumahodx`
- App Store価格: 日本 300円
- データ保存: 端末内の UserDefaults
- 外部API、広告、トラッキング: なし

## 主な機能

- 角度計、2軸水平器、単位変換
- 勾配計算、材料計算、よく使う材料単価
- 測定メモ、現場名、タグ、履歴検索
- OK / NG 自動判定しきい値
- 写真への測定ラベル、矢印、丸印
- 中心線ガイド、現場チェックリスト
- PDFレポート、QR共有、測定スタンプ
- 音声メモ、音と振動による水平通知
