# OAHSPE:α78

広告なし、追跡なし、買い切り前提のiPhoneカメラアプリです。
アプリ名は`OAHSPE:α78`です。
全世界版として、ホーム画面名と権限文言は日本語・英語ローカライズに対応します。

## MVP

- SwiftUI + AVFoundation
- 日本語 / 英語ローカライズ
- カメラプレビュー
- 写真撮影
- 写真ライブラリ保存
- タップフォーカス
- グリッド表示
- 買い切り表示
- `最強手ブレ`モード
- ゼロシャッターラグ / responsive capture / fast capture prioritization の対応検出
- deferred photo delivery の対応検出
- RAW + JPEG撮影の入口
- 3枚露出ブラケット撮影の入口
- 自前ISPモード
- リアルタイムAI現像モード
- セマンティック露出モード
- 目的別プロモード
- 動体別処理モード
- プライバシー検知モード
- リアルタイム解析プレビュー
- 音シャッター
- カメラ監督
- `Zen`、`Ghost`、`Doc`の撮影補助モード

## 売り

- 広告なし、追跡なし、買い切り。
- 撮る前に失敗を教えるカメラ。
- 子供、ペット、スポーツ、表情、ジャンプに強い決定的瞬間モード。
- 拍手、笑い声、「はいチーズ」で撮れる音シャッター。
- 初心者に構図や明るさを教えるカメラ監督。
- iPhoneで撮ったのに、別カメラで撮ったみたいな自前ISP。
- 顔ではなく、写したいものに露出を合わせる。
- メルカリ、ネイル、料理、店舗広告、SNSアイコンで撮影基準を変える。
- 動いている被写体だけ別処理して、背景合成のゴーストを抑える。
- 投稿前に住所、QR、顔、カード番号っぽい写り込みを警告する。
- 逆光、夜景、室内を救う自前HDR合成。
- RAW撮影から自前現像までつなげるプロ素材モード。

## 技術ロードマップ

### 1. 決定的瞬間

- Zero Shutter Lag
- Responsive Capture
- Fast Capture Prioritization
- Deferred Photo Delivery
- 直近60フレームのベストショット候補保持
- ブレ、白飛び、黒つぶれからスコアリング

### 2. RAW現像

- RAW + JPEG同時保存
- `CIRAWFilter`ベースの現像エンジン
- 露出補正、ハイライト復元、シャドウ持ち上げ
- ノイズ低減、シャープネス、色温度、フィルム調LUT
- HEIF/JPEG書き出し

### 2.5 自前ISP / AI現像

- 独自トーンカーブ
- 独自色味
- 料理、人物、商品、フィルム調プリセット
- Vision人物マスクで人物だけ明るく
- Vision文字認識で書類や看板だけくっきり
- Core MLモデルを差し込んで、空、料理、商品、肌を個別補正

### 2.6 セマンティック露出

- 顔優先露出
- 商品優先露出
- 空を飛ばさない露出
- 書類の文字が読める露出
- 白い料理皿を飛ばさない露出
- 黒い服を潰さない露出

### 2.7 目的別プロモード

- メルカリ: 商品中央、背景シンプル、明るい、影少なめ、正方形
- ネイル: 爪先ピント、肌色自然、反射抑えめ、手の角度ガイド
- 料理: 湯気、ツヤ、斜め45度、暖色、皿の白飛び防止
- 店舗広告: 入口、看板、照明、清潔感、文字入れ余白
- SNSアイコン: 顔の明るさ、背景ぼけ、目線、丸型トリミング余白

### 3. 自前HDR

- 3〜5枚ブラケット撮影
- 明るさ正規化
- Optical Flowによる動き検出
- ゴースト除去
- 白飛び、黒つぶれ救済
- 自然なトーンマッピング

### 3.5 動体別処理

- 動いている領域だけマスク化
- 背景は複数枚合成でノイズ低減
- 動く人、車、ペットは一番ブレていないフレームから採用
- 動き方向に合わせてシャープ化
- ゴーストが出そうな部分は合成しない

### 4. リアルタイム解析

- 白飛び警告
- 黒つぶれ警告
- 手ブレ警告
- 水平警告
- ヒストグラム
- ゼブラ
- フォーカスピーキング

### 4.5 音と指示

- 拍手で撮影
- 「はいチーズ」で撮影
- 赤ちゃんの笑い声、ペットの鳴き声、料理音の検出
- 「少し右へ」「光の方へ」「今です」と短く案内
- 画面表示と音声読み上げの両対応

### 4.6 投稿前チェック

- 文字認識で住所、名前、電話番号、郵便番号を警告
- QRコード、バーコードを警告
- 顔の写り込みを警告
- クレカ番号っぽい数字列を警告
- 将来は名札、郵便物、PC画面、鏡の映り込みも検知

### 5. Depth + Segmentation

- LiDAR / Depth対応端末で深度データ取得
- Vision人物セグメンテーション
- Depth + 人物マスク + エッジ検出の二重マスク
- 背景ぼかし、背景暗め、商品浮き上げ

### 6. Multi-frame

- Super Resolution風の高精細化
- 低照度ナイトスタック
- 三脚前提ナイトモード
- 遠くの文字、商品、看板、月、夜景向け

### 7. 動画

- リアルタイムLUT
- LOG風プレビュー
- ゼブラ表示
- フォーカスピーキング
- 波形 / ヒストグラム
- 音声メーター
- 前後同時録画
- シネマティック動画は後回し

## 開発

Macでこのフォルダを開き、XcodeGenでプロジェクトを作ります。

```sh
cd ios/NoAdsCamera
xcodegen generate
open NoAdsCamera.xcodeproj
```

実機で動かすには、Xcodeで`DEVELOPMENT_TEAM`と`PRODUCT_BUNDLE_IDENTIFIER`を自分の値に変更してください。
