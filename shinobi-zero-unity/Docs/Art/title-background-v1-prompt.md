# タイトル背景 v1

OpenAIの組み込み画像生成で制作した、iPhone縦画面用のキービジュアル。

## 最終プロンプト

リアルなAAAゲームのキービジュアル。雨に濡れた夜の山寺を舞台に、黒と藍の装束をまとった一人の忍びを右寄りの三分の二背面で描く。忍びは肩の近くに精密な四方手裏剣を一枚構え、遠景には霧越しの円形標的を置く。冷たい月光、控えめな灯籠の暖色、濡れた木材・石・鋼・布の写実的な質感。上部左側と下部中央はタイトルと操作UIを重ねられる暗い余白にする。2:3縦構図。文字、ロゴ、UI、透かし、現代物、魔法表現、流血は入れない。手指と武器は自然な形にし、手裏剣は一枚だけにする。

既存の敵5人ビジュアルは、写実的な素材感、暗い色調、歴史幻想の方向性だけを参照した。
