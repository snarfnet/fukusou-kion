# 毎日天使からメッセージが届くアプリ仕様

## コンセプト

毎朝、天使語風の短い言葉、日本語メッセージ、英語メッセージが届く。
占いというより、内省と小さな行動を促すアプリにする。

## 表示例

```text
LUMIEL ZIRDO CA ORO

天使は静かに告げます。焦らなくていい。今日の扉は、静かに開きます。

The angel speaks softly. You do not need to rush. Today's door opens quietly.

今日の小さな行動:
朝の光を一分だけ見る。
```

## データ

- `data/angel_messages_365.json`
- 365日分
- 天使語風、日本語、英語、今日の行動、テーマを収録

## 注意

天使語はエノク語に着想を得た雰囲気フレーズとして扱う。
厳密な翻訳とは言わない。

アプリ内では「天使語風」「今日のメッセージ」「内省のための言葉」と表現する。

## 画面案

1. 今日のメッセージ
2. 過去のメッセージ履歴
3. 夢日記
4. 1日1問の天使チャット
5. 願いから作るシジル画像

まずは「今日のメッセージ」と「履歴」だけでMVPにできる。
