# 盛り盛りフォトメーカー デザイン方針

## 方向性

- 高校生から20代向けの、盛れるピンク系コスメアプリ。
- 低年齢向けの強い玩具感より、白・淡ピンク・透明感・パール・リボン・ハートを使った上品かわいい方向。
- 実写参考画像は直接使わず、UI文法だけ参考にする。

## UIモチーフ

- 中央に大きなぷっくりロゴ。
- 白ベースの淡いピンク背景。
- パールガーランド、リボン、ハート、星のきらめき。
- 大きめの「写真を選ぶ」CTA。
- テンプレート、スタンプ、フィルター、パーツのようなカード型入口。
- ボタンは角丸で、透明感のあるピンクグラス調。

## 避けること

- 子ども向けに見えすぎる強すぎる彩度。
- 文字が読めないほど装飾の濃いボタン。
- 実写人物画像をUI素材として直接使うこと。
- 画面全体を濃いピンク一色にすること。

## iOS版への引き継ぎ

- ホーム画面は参考画像のような縦スクロール構成にする。
- 編集画面は現在のWeb版の操作性を維持し、素材カテゴリとレイヤー操作を下部またはサイドにまとめる。
- 課金パックは `free`, `morimoriPack1`, `morimoriPack2` の区分を使う。
