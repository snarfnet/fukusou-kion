# そこそこ時間を潰せる

今いる場所の近くから、無料または低料金で、涼しく過ごせる施設を探すiOSアプリです。

## 開き方

1. macOSで `brew install xcodegen` を実行します。
2. このフォルダで `xcodegen generate` を実行します。
3. `Himahie.xcodeproj` をXcode 15以降で開きます。
4. iOS 17以降の端末またはシミュレータで実行します。

位置情報を許可しない場合は、選んだ都道府県の中心から距離を計算します。営業時間や料金、設備は変わるため、利用前に公式情報も確認してください。

## 施設データ

施設は都道府県ごとの `spots_XX.json` に分割しています。`prefectures.json` は各ファイルの索引です。アプリは選択中の都道府県だけを読み込みます。

2026年7月23日時点で11,833件を収録しています。対象は図書館、博物館、ギャラリー、文化・展示施設、ビジターセンター、無料見学施設です。一般的な公共施設、市役所・区役所ロビーは含めていません。

`scripts/collect_osm_spots.py` はGeofabrikのOpenStreetMap日本抽出データから施設を収集し、47都道府県へ分割します。Python 3.11と `osmium` が必要です。公式サイトで料金や営業時間を確認した施設は `verified_spots.json` で管理し、収集時に優先して反映します。
