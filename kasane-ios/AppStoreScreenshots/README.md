# KASANE App Store screenshots

The `iphone-67` folder contains 1290 × 2796 promotional concepts for the 6.7-inch iPhone slot:

1. Nationwide discovery and 1,000 stories
2. GPS historical time lens
3. Sourced story, timeline, and nearby traces

Files ending in `-source.png` preserve the original generated artwork. Files without that suffix are the App Store-sized exports.

The visuals were generated with the built-in image generation tool. Before release, replace concept UI with deterministic simulator captures if Apple review or product accuracy requires exact in-app rendering.
